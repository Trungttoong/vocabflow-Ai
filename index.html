    📤 Xuất từ vựng sang Google Sheets

    Mỗi dòng có cột Ngày (ngày bạn luyện từ đó):

    Cách 1 · Gửi thẳng lên Google Sheets
    Cài đặt 1 lần (chưa có link?)
    1. Mở Google Sheet Từ vựng → menu Tiện ích mở rộng → Apps Script.
    2. Xóa code cũ, dán đoạn code bên dưới, bấm Lưu.
    3. Bấm Triển khai → Tùy chọn triển khai mới → loại Ứng dụng web.
    4. "Thực thi với tư cách": Tôi. "Ai có quyền truy cập": Bất kỳ ai. Bấm Triển khai, cấp quyền khi Google hỏi.
    5. Copy URL ứng dụng web dán vào ô ở trên. Chỉ cần làm 1 lần, link được lưu trong trình duyệt này.
    Cách 2 · Không cần cài đặt

    CSV: trong Google Sheets chọn Tệp → Nhập → Tải lên → "Chèn trang tính mới" hoặc "Thêm vào trang tính hiện tại". Sao chép: bấm vào ô A1 (hoặc ô trống dưới dữ liệu cũ) rồi nhấn Ctrl+V.

    Xem trước 1 thẻ
    🖼️ Xem trước & chọn ảnh từng từ

    Đây là ảnh sẽ đi kèm mỗi thẻ khi bạn tải gói .apkg. Bấm ↻ để đổi ảnh, 🔎 để tìm trên Google rồi 📋 Dán ảnh bạn chọn (hoặc bấm vào dòng rồi Ctrl+V), 🚫 để thẻ không có ảnh.

    📦 Gói kèm ảnh minh họa (.apkg)

    Ảnh được gắn thẳng vào ô Front của thẻ (nằm dưới từ và câu ví dụ), nên hiện ngay khi bạn gõ đáp án. Cần có mạng lúc tạo gói để tải ảnh. Nhập bằng File → Import như file .txt.

    Cách nhập vào Anki
    1. Mở Anki → menu File → Import (hoặc nút Import File ở màn hình chính).
    2. Chọn file .txt vừa tải. Hai loại thẻ nên nhập vào hai deck khác nhau (đổi tên deck ở trên giữa hai lần tải, vd "Anh-Việt" và "Việt-Anh").
    3. Kiểm tra Note Type = Basic (type in the answer), Deck đúng ý (có thể đổi sang deck có sẵn), rồi bấm Import.
    4. Mỗi từ có mã riêng, nên nhập lại file mới sẽ cập nhật thẻ cũ chứ không tạo trùng.

    Cần Anki bản 2.1.54 trở lên (bản của bạn đã đủ). Nếu Anki của bạn không phải tiếng Anh và không có Note Type tên "Basic (type in the answer)", hãy chọn thủ công ở bước 3.
